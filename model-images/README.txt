SERVO CYCLER - MODEL PICTURE (ABRC)

The Lua package installs the script only. The model picture has to be copied
to the radio by hand, once:

1. Connect the radio to the computer with USB (choose the storage / "SD card" mode).
2. Pick the folder below for your radio and copy  svcycler.png  into
       bitmaps/models/
   - X20 / X20S / X20RS / X20 Pro .... SD card
   - X18 / X18S / X18SE / Twin ........ internal storage (RADIO / NAND);
                                         a copy on the SD card works too
   - X14 .............................. the drive that already has bitmaps/models
   - X10 / X12S ....................... SD card
3. On the radio: Model setup > Picture > svcycler

Folders and sizes:
   X20_X20S_X20RS   300 x 280
   X18_X18S_Twin    180 x 166
   X14              240 x 224   (no official size published; if it does not
                                 fit, use the X18 or X20 picture instead)
   X10_X12S         180 x 160

PNG is used because it shows on every Ethos radio.
